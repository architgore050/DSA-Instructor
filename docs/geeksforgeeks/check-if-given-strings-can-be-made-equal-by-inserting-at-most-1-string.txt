Title: Check if given Strings can be made equal by inserting at most 1 String
Extractor: 2

Given two strings s1 and s2 , the task is to check if the given strings can be made equal by inserting at most one string to one of the strings at any index.

Examples:

> Input : s1 = "geeksforgeeks", s2 = "geeksgeeks" Output : Yes Explanation: Add string "for" after 4th index to s2. Input: s1 = "geekforgeeks", s2 = "geeksgeeks" Output: No Explanation: string s1 has extra "for" and s2 has an extra "s".

Approach:

> The idea is to find the longest matching prefix and suffix between both strings, and then check if the remaining part of the longer string can be inserted into the shorter string to make them equal.

Step by step approach:

1. Check if strings are of equal length; if yes, simply compare the two strings.
2. Ensure s2 is the shorter string (swap if needed).
3. Find the length of matching prefix from the beginning of both strings.
4. Find the length of matching suffix from the end of both strings.
5. Check if the matching parts (prefix + suffix) cover the entire shorter string. If they do, return true (meaning we can insert the middle part of s1 into s2).

Illustration:

> Taking example: s1 = "geeksforgeeks", s2 = "geeksgeeks" Matching prefix: "geeks" (length 5) Matching suffix: "geeks" (length 5) Total matched = 5 + 5 = 10, which is equal to length of s2. This means there's an overlap, and s2 is completely covered. Adding string "for" after 4th index will make both the strings equal.

C++

// C++ program to Check if given Strings can
// be made equal by inserting at most 1 String
#include <bits/stdc++.h>
using namespace std;

bool isEqual(string &s1, string &s2) {

    // If length of both string is same
    // simply compare them
    if (s1.length() == s2.length()) {
        return s1 == s2;
    }

    // Ensuring s2 is the string with
    // smaller length
    if (s1.length() < s2.length()) {
        return isEqual(s2, s1);
    }

    int n = s1.length();
    int m = s2.length();

    // Find matching prefix length
    int i = 0;
    while (i < m && s1[i] == s2[i]) {
        i++;
    }

    // Find matching suffix length
    int j = 0;
    while (j < m && s1[n - 1 - j] == s2[m - 1 - j]) {
        j++;
    }

    // Check if the entire shorter string is
    // covered by matching prefix and suffix
    return (i + j >= m);
}

int main() {
    string s1 = "geeksforgeeks";
    string s2 = "geeksgeeks";
    if (isEqual(s1, s2)) {
        cout << "Yes" << endl;
    }
    else {
        cout << "No" << endl;
    }
    return 0;
}
