Title: Missing Element in Range
Extractor: 2

Given an array arr[] of integers and a range [low, high], find all the numbers within the range that are not present in the array. return the missing numbers in sorted order.

Examples:

> Input: arr[] = [10, 12, 11, 15], low = 10, high = 15 Output: [13, 14] Explanation: Numbers 13 and 14 lie in the range [10, 15] but are not present in the array. Input: arr[] = [1, 4, 11, 51, 15], low = 50, high = 55 Output: [50, 52, 53, 54, 55] Explanation: Numbers 50, 52, 53, 54 and 55 lie in the range [50, 55] but are not present in the array.

Table of Content

- [Naive Approach] Using Linear Search for Every Number - O((high - low + 1) * n) Time and O(1) Space
- [Better Approach] Using Sorting - O(n Log n) Time and O(1) Space
- [Expected Approach - 1] Using Hash Set - O(n + (high - low + 1)) Time and O(n) Space
- [Expected Approach - 2] Using Boolean Array - O(n + (high - low + 1)) Time and O(high - low + 1) Space

### [Naive Approach] Using Linear Search for Every Number - O((high - low + 1) * n) Time and O(1) Space

> The idea is to iterate through every number in the range [low, high] and search for it in the array using a linear scan. If the number is not found, add it to the result.

C++

#include <iostream>
#include <vector>
using namespace std;

vector<int> missingRange(vector<int> &arr, int low, int high)
{
    vector<int> res;

    // Check every number in the given range
    for (int num = low; num <= high; num++)
    {

        bool found = false;

        // Search current number in the array
        for (int x : arr)
        {
            if (x == num)
            {
                found = true;
                break;
            }
        }

        // If not present, add to result
        if (!found)
            res.push_back(num);
    }

    return res;
}

int main()
{

    vector<int> arr = {1, 4, 11, 51, 15};
    int low = 50, high = 55;

    vector<int> res = missingRange(arr, low, high);

    cout << "[";

    for (int i = 0; i < res.size(); i++)
    {
        cout << res[i];
        if (i != res.size() - 1)
            cout << ", ";
    }

    cout << "]";

    return 0;
}

### [Better Approach] Using Sorting - O(n Log n) Time and O(1) Space

> The idea is to sort the array first. Then traverse the range [low, high] while simultaneously scanning the sorted array. If the current range value matches the array element, move to the next array element; otherwise, the number is missing, so add it to the result.

Working of Approach:

- Sort the array so that its elements are in increasing order.
- Traverse every number from low to high while maintaining a pointer to the sorted array.
- Move the pointer forward until it reaches an element greater than or equal to the current number.
- If the current number is not present at the pointer, add it to the result as a missing number.
- Continue until all numbers in the given range are checked, then return the result.

C++

#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

vector<int> missingRange(vector<int> &arr, int low, int high)
{
    // Sort the array
    sort(arr.begin(), arr.end());

    vector<int> res;
    int i = 0;
    int n = arr.size();

    // Traverse all numbers in the range
    for (int x = low; x <= high; x++)
    {
        // Skip elements smaller than the current number
        while (i < n && arr[i] < x)
            i++;

        // If current number is missing, add it
        if (i == n || arr[i] != x)
            res.push_back(x);
    }

    return res;
}

### [Expected Approach - 1] Using Hash Set - O(n + (high - low + 1)) Time and O(n) Space

> The idea is to store all array elements in a hash set. Then iterate through every number in the range [low, high] and add the numbers that are not present in the hash set to the result.

Working of Approach:

- Store all elements of the array in an unordered_set for constant-time lookup.
- Traverse every integer from low to high.
- For each number, check whether it exists in the hash set.
- If the number is not found, add it to the result array as a missing number.
- After checking the complete range, return the result containing all missing numbers.

C++

#include <iostream>
#include <unordered_set>
#include <vector>
using namespace std;

vector<int> missingRange(vector<int> &arr, int low, int high)
{

    // Store all array elements in a hash set
    unordered_set<int> s;
    for (int x : arr)
    {
        s.insert(x);
    }

    vector<int> res;

    // Check every number in the given range
    for (int x = low; x <= high; ++x)
    {

        // If number is not present, add it to the result
        if (s.find(x) == s.end())
            res.push_back(x);
    }

    return res;
}

{

    {
        cout << res[i];
        if (i != res.size() - 1)
            cout << ", ";
    }

    cout << "]";

    return 0;
}

### [Expected Approach - 2] Using Boolean Array - O(n + (high - low + 1)) Time and O(high - low + 1) Space

> The idea is to create a boolean array to mark the numbers present in the given range [low, high]. Traverse the array and mark every valid element. Finally, iterate through the boolean array and add all unmarked numbers to the result.

Working of Approach:

- Create a boolean array of size (high - low + 1) to represent all numbers in the given range.
- Traverse the array and mark the elements that lie within [low, high] as present.
- Iterate through the boolean array and identify the unmarked positions.
- Add the corresponding numbers to the result and return the list of missing numbers.

C++

#include <iostream>
#include <vector>
using namespace std;

vector<int> missingRange(vector<int> &arr, int low, int high)
{
    int m = high - low + 1;

    // Mark the numbers present in the range
    vector<bool> present(m, false);

    for (int x : arr)
    {
        if (x >= low && x <= high)
            present[x - low] = true;
    }

    vector<int> res;

    // Collect all missing numbers
    for (int i = 0; i < m; i++)
    {
        if (!present[i])
            res.push_back(low + i);
    }

    return res;
}

    {
