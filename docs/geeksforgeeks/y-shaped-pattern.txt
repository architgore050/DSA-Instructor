Title: Y shaped pattern
Extractor: 2

Print a ‘Y’ shaped pattern from asterisks in N number of lines.

Examples :

> Input : N = 12 Output : *             * *           * *         * *       * *     * *   * * * * * * * * Input : 8 Output : *         * *       * *     * *   * * * * * *

Approach :

Follow the steps to solve this problem:

- Initialize two variable s = N / 2 and t = N / 2.
- Traverse a loop on i from 0 till N-1
- Check if i > s Traverse a loop on j from 0 till s-1 and print " " i.e., space
- Else, Iterate on j from 0 till i-1 and print " " i.e., space Then print "*" i.e., asterisk Iterate on k from 0 till 2*t-1 and print " " i.e., space Decrement t by 1 .
- Print " *" at the end of each iteration.

Below is the implementation of the above approach:

C++

// C++ code for the above approach

#include <iostream>
using namespace std;

int main()
{

    // Given integer N
    int N = 12;

    // Initialize s and t
    int s = N / 2;
    int t = s;

    // Traverse from 0 till N
    for (int i = 0; i < N; i++) {

        if (i > s) {

            for (int j = 0; j < s; j++)
                cout << " ";
        }
        else {

            for (int j = 0; j < i; j++)
                cout << " ";

            cout << "*";

            for (int k = 0; k < 2 * t; k++)
                cout << " ";

            // Decrement t
            t--;
        }

        cout << " *" << endl;
    }

    return 0;
}
